# 🌐 Lenguaje de Marcas y Sistemas de Gestión de Información

Markup languages, web standards, and information management systems coursework for 1st year of DAM (Desarrollo de Aplicaciones Multiplataforma) / Teoría, prácticas y proyectos de HTML5, CSS3, XML, XSD, DTD, XSLT y XQuery del módulo de Lenguaje de Marcas.

---

## 🗂️ Estructura del Repositorio

El contenido del módulo está organizado en bloques temáticos principales:

* **`Fundamentos-HTML5-CSS3/`**: Estructura web semántica, hojas de estilo, diseño adaptativo y maquetación moderna.
* **`Ecosistema-XML-XSD-XSLT/`**: Modelado de datos estructurados, validación mediante DTD y esquemas XSD, transformaciones con XSLT y consultas con XQuery (incluyendo casos prácticos y simulacros de examen).

---

## 📚 Tecnologías y Estándares

* **Web Standards**: HTML5, CSS3 (Flexbox/Grid).
* **XML Ecosystem**: XML, DTD (Document Type Definition), XSD (XML Schema Definition).
* **Transformación y Consulta**: XSLT (Extensible Stylesheet Language Transformations) y XQuery.
