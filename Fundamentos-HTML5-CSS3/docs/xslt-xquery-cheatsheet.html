📌 XPath — Navegación en XML

¿Qué es XPath?

Lenguaje de consulta para navegar por la estructura de árbol de un documento XML. Se usa dentro de XSLT y XQuery para seleccionar nodos.

Tipos de nodos

TipoEjemplo
Elemento<nombre>
Atributoid="p01"
TextoContenido textual del nodo
RaízNodo raíz del documento

Ejes de XPath

Símbolo / EjeSignificado
/Desde la raíz (ruta absoluta)
//En cualquier nivel (descendientes)
.Nodo actual
..Nodo padre
@Atributo
*Cualquier elemento hijo
child::Hijos directos
ancestor::Ancestros
descendant::Todos los descendientes
following-sibling::Hermanos siguientes
preceding-sibling::Hermanos anteriores

Predicados — Filtros con [ ]

Por atributo

(: Persona con id exacto :)
//persona[@id="p02"]

(: Personas que TIENEN atributo id :)
//persona[@id]

(: Atributo con valor concreto :)
//movimiento[tipo="ingreso"]

Por posición

(: Primer elemento :)
/biblioteca/libros/libro[1]

(: Último elemento :)
/biblioteca/libros/libro[last()]

(: Posición específica :)
//persona[position()=2]

Por existencia de hijo

(: Personas que tienen móvil :)
//persona[telefonos/movil]

(: Personas que tienen teléfono casa :)
//persona[telefonos/casa]

(: Libros con préstamos activos :)
//libro[estado_prestamos/prestamo]

Operadores lógicos

(: AND :)
//baile[sala=1 and precio > 25]

(: OR :)
//baile[sala=1 or sala=2]

(: NOT :)
//persona[not(telefonos/movil)]

(: Comparaciones :)
//cuenta[fechaApertura > '2022-01-01']

🔄 XSLT — Transformación de XML

¿Qué es XSLT?

XSLT (eXtensible Stylesheet Language Transformations) transforma documentos XML en otros XML, HTML, texto, etc., usando plantillas y expresiones XPath.

💡 Los ficheros XSLT tienen extensión .xsl y son XML válidos con el namespace xmlns:xsl="http://www.w3.org/1999/XSL/Transform"

Estructura base obligatoria

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="2.0"
  xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

  <!-- Tipo de salida: xml | html | text -->
  <xsl:output method="xml" indent="yes" encoding="UTF-8"/>

  <!-- Plantilla principal: match="/" = raíz del doc -->
  <xsl:template match="/">
    <!-- aquí va la transformación -->
  </xsl:template>

</xsl:stylesheet>

xsl:value-of — Extraer valor

Extrae el contenido de texto de un nodo.

<nombre>
  <xsl:value-of select="identificadores/nombre"/>
</nombre>

<!-- Con función concat :-->
<nombre_completo>
  <xsl:value-of select="concat(identificadores/nombre,
    ' ', identificadores/apellidos)"/>
</nombre_completo>

xsl:for-each — Iterar nodos

Recorre un conjunto de nodos y aplica la transformación a cada uno.

<contactos>
  <xsl:for-each select="agenda/contactos/persona">
    <contacto id="{@id}">
      <nombre>
        <xsl:value-of select="identificadores/nombre"/>
      </nombre>
    </contacto>
  </xsl:for-each>
</contactos>
💡 {@id} es un AVT (Attribute Value Template) — inserta el valor del atributo id dinámicamente.

xsl:apply-templates — Delegar a plantillas

Llama a otras plantillas definidas con xsl:template match=

<!-- En la plantilla principal :-->
<xsl:apply-templates select="agenda/contactos/persona"/>

<!-- Plantilla específica para persona :-->
<xsl:template match="persona">
  <tr>
    <td><xsl:value-of select="identificadores/nombre"/></td>
    <td><xsl:value-of select="telefonos/movil"/></td>
  </tr>
</xsl:template>

xsl:if — Condición simple

<xsl:if test="telefonos/movil">
  <movil><xsl:value-of select="telefonos/movil"/></movil>
</xsl:if>

<!-- Con predicado numérico :-->
<xsl:if test="count(telefonos/*) > 1">
  <multiples-telefonos/>
</xsl:if>

xsl:choose — Condición múltiple

<xsl:choose>
  <xsl:when test="estado_prestamos/prestamo">SI</xsl:when>
  <xsl:otherwise>NO</xsl:otherwise>
</xsl:choose>

xsl:sort — Ordenar resultados

<xsl:for-each select="contactos/persona">
  <!-- Dentro del for-each, antes del contenido :-->
  <xsl:sort select="identificadores/apellidos"/>
  <!-- También se puede: order="descending" :-->
  <xsl:sort select="importe" order="descending"
            data-type="number"/>
  <contacto>...</contacto>
</xsl:for-each>

xsl:copy-of — Copiar nodo con hijos

<!-- Copia el nodo telefonos con todos sus hijos :-->
<xsl:copy-of select="telefonos"/>

<!-- Copia el nodo persona[@id='p02'] completo :-->
<xsl:copy-of select="//persona[@id='p02']"/>
⚠️ copy-of copia etiquetas + contenido. value-of solo copia el texto.

🔍 XQuery — Consultas sobre XML

¿Qué es XQuery?

Lenguaje de consulta sobre documentos XML. Similar a SQL pero para XML. Usa la estructura FLOWR y permite generar nuevos documentos XML como resultado.

Estructura FLOWR — La clave de XQuery

F
FOR — Itera sobre un conjunto de nodos
for $p in /agenda/contactos/persona
for $p AT $posicion in /agenda/contactos/persona opcional
L
LET — Asigna una expresión a una variable opcional
let $nombre := $p/identificadores/nombre
let $total := count(//persona)
O
ORDER BY — Ordena los resultados opcional
order by $p/identificadores/apellidos
order by $p/importe descending
W
WHERE — Filtra los resultados opcional
where $p/direccion/localidad = "Santander"
R
RETURN — Define el resultado obligatorio
return <persona>{ $p/identificadores/nombre }</persona>
return ($var1, $var2) ← varios valores: entre paréntesis
💡 Las llaves { } intercalan código XQuery dentro de etiquetas XML.
💡 data() devuelve el valor del nodo sin etiquetas: data($p/nombre)

Plantilla básica XQuery

<resultado>
{
  for $p in /agenda/contactos/persona
  where $p/direccion/localidad = "Santander"
  order by $p/identificadores/apellidos
  return
    <persona id="{ $p/@id }">
      <nombre>{ $p/identificadores/nombre/text() }</nombre>
      <apellidos>{ $p/identificadores/apellidos/text() }</apellidos>
    </persona>
}
</resultado>

FunciónDescripción

Condicional en XQuery — if/then/else

if (exists($existe)) then
  ()  (: no hacer nada :)
else
  <resultado>...</resultado>

(: Anidado :)
if ($b/precio/@cuota = "trimestral")
then replace value of node $b/precio 
     with string(xs:decimal(normalize-space($b/precio)) * 0.90)
else if ($b/precio/@cuota = "anual")
then replace value of node $b/precio 
     with string(xs:decimal(normalize-space($b/precio)) * 0.85)
else ()

Ejercicio 6
Contar cuántas personas viven en cada localidad (agrupar con distinct-values + LET)
<localidades>
{
  for $loc in distinct-values(
    (/agenda/propietario | /agenda/contactos/persona)/direccion/localidad)
  let $num := count(
    (/agenda/propietario | /agenda/contactos/persona)
    [direccion/localidad = $loc])
  order by $loc
  return
    <localidad nombre="{$loc}">
      <habitantes>{ $num }</habitantes>
    </localidad>
}
</localidades>

🎓 Simulacro de Examen — Respuestas incluidas

PARTE 1 — Test teórico (10 preguntas)

Pregunta 1
¿Qué hace la expresión XPath //persona[@id="p02"]/*/*?
  • ✓ a) Selecciona todos los nietos del elemento persona con id "p02"
  • b) Selecciona todos los hijos del elemento persona con id "p02"
  • c) Selecciona el atributo id del elemento persona
  • d) Selecciona todos los persona que tienen hijos
📌 [@id="p02"] filtra por atributo. El primer * selecciona todos los hijos directos (identificadores, direccion, telefonos...) y el segundo * los hijos de esos (nombre, apellidos, calle, movil...) — es decir, los nietos.
Pregunta 2
¿Cuál es la diferencia entre xsl:copy-of y xsl:value-of?
  • a) No hay diferencia, hacen lo mismo
  • ✓ b) copy-of copia el nodo completo con etiquetas e hijos; value-of solo extrae el texto
  • c) value-of copia el nodo completo; copy-of solo el texto
  • d) copy-of solo funciona con atributos
📌 <xsl:copy-of select="telefonos"/> genera: <telefonos><movil>970123123</movil></telefonos>. <xsl:value-of select="telefonos/movil"/> genera solo: 970123123
Pregunta 3
En XQuery, ¿qué hace distinct-values(//localidad)?
  • a) Cuenta las localidades únicas
  • ✓ b) Devuelve una secuencia con las localidades sin duplicados
  • c) Ordena las localidades alfabéticamente
  • d) Elimina los nodos localidad del XML
📌 Es esencial para agrupar. Ejemplo: si hay 2 personas en Santander y 2 en Torrelavega, distinct-values() devuelve ["Santander", "Torrelavega"], que luego usamos para contar con count() en el let.
Pregunta 4
¿Qué instrucción XSLT permite hacer una condición tipo if/else?
  • a) xsl:if
  • ✓ b) xsl:choose con xsl:when y xsl:otherwise
  • c) xsl:select
  • d) xsl:when solo
📌 xsl:if no tiene "else". Para múltiples condiciones se usa xsl:choose / xsl:when / xsl:otherwise. Es lo que usamos en la biblioteca para mostrar "SI" o "NO" en el campo <prestado>.
Pregunta 5
¿Qué representa {@id} en una etiqueta de salida XSLT como <cuenta id="{@id}">?
  • a) Un comentario XML
  • b) Una variable XSLT predefinida
  • ✓ c) Un AVT (Attribute Value Template) que inserta el valor del atributo id dinámicamente
  • d) Un error de sintaxis
📌 Los AVT permiten usar expresiones XPath dentro de atributos usando llaves {}. Sin las llaves, id="@id" pondría literalmente el texto "@id". Con llaves id="{@id}" pone el valor real, p.ej. "ACC-001".
Pregunta 6
¿Cuál es la expresión XPath para obtener el id de todas las personas que tienen teléfono móvil?
  • a) //persona/telefonos/movil
  • b) //persona[@movil]/@id
  • ✓ c) //persona[telefonos/movil]/@id
  • d) //persona/movil/../@id
📌 El predicado [telefonos/movil] filtra solo las personas que TIENEN el elemento movil. Luego /@id extrae el atributo id de esas personas.
Pregunta 7
En XQuery, ¿qué operaciones de Update SOLO están disponibles en Saxon Enterprise Edition?
  • a) FOR, LET, RETURN
  • ✓ b) INSERT, REPLACE, DELETE
  • c) WHERE, ORDER BY
  • d) count(), sum(), concat()
📌 Las operaciones de modificación de documentos XML (XQuery Update Facility) requieren Saxon EE. Saxon HE solo permite consultas de lectura. Comando: java -cp saxon-ee-12.9.jar net.sf.saxon.Query -update:on -s:fichero.xml -q:consulta.xq
Pregunta 8
¿Qué devuelve //contactos/persona/telefonos/casa/../../@id?
  • a) El id de los elementos casa
  • b) Los teléfonos de casa de todos los contactos
  • ✓ c) El id de las personas que tienen teléfono de casa
  • d) Los datos del elemento telefonos
📌 La ruta baja hasta casa, luego ../.. sube dos niveles: primero a telefonos, luego a persona. Finalmente @id obtiene el atributo id de persona. Es un patrón muy típico en examen.
Pregunta 9
¿Cuál es la estructura correcta FLOWR en XQuery?
  • a) FOR → WHERE → LET → ORDER → RETURN
  • b) FOR → RETURN → WHERE → ORDER → LET
  • ✓ c) FOR → LET → ORDER BY → WHERE → RETURN (F-L-O-W-R)
  • d) WHERE → FOR → LET → RETURN → ORDER
📌 FLOWR: For → Let → Order by → Where → Return. Solo FOR y RETURN son obligatorios. LET, ORDER BY y WHERE son opcionales.
Pregunta 10
¿Qué hace <xsl:apply-templates select="agenda/contactos/persona"/> diferente de <xsl:for-each select="agenda/contactos/persona">?
  • a) No hay diferencia
  • ✓ b) apply-templates delega el procesamiento a una plantilla match="persona" definida por separado; for-each procesa inline
  • c) for-each solo funciona con un elemento a la vez
  • d) apply-templates no acepta XPath
📌 apply-templates busca una plantilla con match="persona" y la aplica a cada nodo. Permite mejor organización del código. for-each lo hace todo inline en el mismo template.
